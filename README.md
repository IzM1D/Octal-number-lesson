# Тест

Статический тест для публикации на GitHub Pages. При каждой загрузке случайно назначается один из 4 вариантов. В тесте 19 заданий: 10 заданий варианта и 9 общих заданий по рабочему листу.

## Публикация

Загрузите файлы в репозиторий GitHub и включите Pages для ветки `main`, папки `/ (root)`. Проект не требует Node.js или сборки.

## Google Sheets

URL веб-приложения уже прописан в `app.js`. Клиент отправляет JSON с полями `studentName`, `variant`, `completedAt`, `score`, `total`, `answers` и `results`. Поле `results` содержит сериализованный полный результат и удобно для отдельного столбца `результаты`. Имя и фамилия используются как идентификатор записи. На стороне Apps Script нужен обработчик, который записывает данные в лист таблицы:

Готовый код находится в файле `google-apps-script.gs`. Его нужно полностью скопировать в редактор Apps Script, заменить содержимое проекта и развернуть как веб-приложение:

1. Откройте `script.google.com` и создайте новый проект.
2. Вставьте содержимое `google-apps-script.gs`.
3. Нажмите «Развернуть» → «Новое развертывание» → «Веб-приложение».
4. Выполнять от имени: «Меня».
5. У кого есть доступ: «Все».
6. Скопируйте URL `/exec` и укажите его в `SHEETS_ENDPOINT`, если URL изменится.

Скрипт открывает таблицу по ID, использует лист `результаты`, создает заголовки при пустом листе и обновляет существующую строку по имени вместо добавления дубликата. Он также отправляет открытые ответы в указанную модель через `UrlFetchApp`.

```js
function doPost(e) {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  const data = JSON.parse(e.postData.contents);
  sheet.appendRow([data.studentName, data.completedAt, data.variant, data.score, data.total, data.results]);
  return ContentService.createTextOutput('ok');
}
```

Если нужно строго запрещать повторную отправку одного имени, это также должно быть добавлено в Apps Script: перед `appendRow` нужно найти имя в первом столбце и заменить существующую строку или вернуть отказ.

## Проверка открытых ответов нейросетью

Открытые ответы сейчас сверяются с эталонными значениями в `app.js`. Для проверки смысловых ответов из рабочего листа нейросеть нужно подключить через серверный прокси, потому что браузерный запрос к OpenAI-compatible API может быть заблокирован CORS и раскрывает ключ посетителям. Прокси должен принимать ответ и возвращать `isCorrect`; после этого его можно подключить в функции `scoreQuiz`.

Переданный API-ключ не добавлялся в проект: URL и ключ нельзя безопасно публиковать в GitHub Pages.
